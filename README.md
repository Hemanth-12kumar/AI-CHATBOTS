AI Chatbot using Ollama 🤖

A command-line-based AI chatbot developed using Python and Ollama. The application uses locally running open-source Large Language Models (LLMs) to understand user queries and generate intelligent, context-aware responses directly in the terminal.

This project demonstrates how to build and interact with a local AI chatbot without requiring a graphical user interface or paid API keys.

Features

Terminal-based conversational chatbot

Local LLM integration using Ollama

Natural language understanding

Context-aware conversations

Open-source AI model support

No graphical user interface required

No paid API keys required

Runs locally on your machine

Technologies Used

Python

Ollama

Large Language Models (LLMs)

Project Objective

To build a simple, locally running conversational AI chatbot using Python and Ollama, demonstrating the practical implementation of Generative AI and open-source LLMs without relying on external paid APIs.
